Thu: Lecture 21 — Harness Engineering: Why Agents Fail and What a Harness Is (Nov 12)

  • Agent = Model + Harness: the model is fixed; the harness is what you engineer
  • Two core failure modes: over-ambition (context exhausted mid-task, leaving undocumented wreckage) and premature victory declaration (agent claims done when it isn’t)
  • Guides (feedforward) vs. sensors (feedback): examples of each and the failure modes they address
  • Five harness subsystems: Instructions, State, Verification, Scope, Session Lifecycle — and the failure mode each prevents
  • Why one giant instruction file fails: progressive disclosure beats encyclopedic reference
  • Harnessability: why strongly-typed languages and clear module boundaries make better harness targets
